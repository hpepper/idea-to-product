# Running notes

- Keep running commentary in a `<DOCUMENT>_running_notes.md` file named after the document it concerns, for example `<app>/docs/REQUIREMENTS_running_notes.md` for `<app>/docs/REQUIREMENTS.md`.
- Never write LLM instructions in a `*_running_notes.md` file.
